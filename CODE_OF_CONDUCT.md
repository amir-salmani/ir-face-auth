# Code of conduct

## The short version

Be decent. Assume good faith. Critique code and claims, not people.

## Specifics that matter here

**Attack reports are welcome, always.** If you defeat the liveness check or
find a way to authenticate as someone else, that is a contribution, not an
attack on the author. Nobody will be treated as hostile for breaking this.
Reports of real weaknesses are the point.

**Do not post other people's biometric data.** No face images in issues or pull
requests — yours or anyone else's. Report numbers. If an image is genuinely
necessary to explain something, ask first.

**Do not overstate security properties.** This applies to maintainers as much
as contributors. If a claim is not backed by measurement, it must say so.
Someone may deploy this on a machine that matters to them, and confident
language they cannot verify is a way of misleading them.

## Unacceptable

Harassment, personal attacks, discriminatory language, publishing others'
private information, and persistent disruption after being asked to stop.

## Enforcement

Report to **hi@amirsalmani.com**. Reports stay confidential. Responses range
from a request to change behaviour up to a permanent ban, depending on
severity. Maintainers are held to the same standard, and a maintainer's
violation is treated more seriously, not less.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.
